# RAINBOW: color studio

Created by Mariam J. A single-file website for choosing colors for websites, apps and systems. No build step, no dependencies.

## Features

- Color wheel with brightness slider and hex input
- Six harmony modes: analogous, monochrome, complementary, split complementary, triadic, tetradic
- Lock colors, edit any swatch, press Space to generate a new palette
- WCAG contrast checker
- Live preview on a website and a mobile app screen, in dark and light themes
- Gradient builder, including a space glow style
- Palette extraction from any image (runs locally in the browser)
- Export to CSS variables, SCSS, Tailwind, JSON, Flutter and Android XML
- Preset and saved palettes, share links, PNG download
